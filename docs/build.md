# Сборка внешнего отчёта или обработки

Нужна установленная платформа 1С:Предприятие. В отдельной тестовой базе используйте конфигуратор и штатную загрузку внешнего отчёта/обработки из файлов.

Корневой файл: `src/АдминистрированиеИАудитПользователей.xml`. Результат сохраните в `.epf`.

Для пакетной сборки конфигуратор поддерживает `/LoadExternalDataProcessorOrReportFromFiles`: сначала указывается корневой XML, затем путь выходного файла. При выгрузке используется `/DumpExternalDataProcessorOrReportToFiles`: сначала путь корневого XML, затем существующего EPF/ERF.

После сборки выполните обратную выгрузку и сравните файлы с `src`. Совпадение исходников не заменяет функциональную проверку на целевой конфигурации. В репозитории нет платформы, типовой конфигурации или лицензии на их использование.
